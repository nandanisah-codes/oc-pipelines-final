# OC Pipelines Final

## Project Name: oc-pipelines-final

This project implements a CI/CD pipeline using GitHub Actions 
and OpenShift Tekton Pipelines for a dealer evaluation system.

### Microservices
- Product Details Microservice
- Dealer Pricing Microservice  
- Dealer Evaluation Frontend

### Pipeline Steps
- Lint with Flake8
- Unit testing with Nose
- Container build with Buildah
- Deployment using OpenShift Client
